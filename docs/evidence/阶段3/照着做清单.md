# 阶段 3 照着做清单

## 启动

```bash
cd /Volumes/飞刀/Personal-Agent-main
find . -name '._*' -delete
cp .env.example .env          # 至少填 AUTH_SECRET；真实模型再填 KIMI_API_KEY / VISION_*
source .venv/bin/activate 2>/dev/null || true
~/pa-venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8787
```

打开 http://127.0.0.1:8787 。

## 自己点一遍

1. **建档**：点左下角搭子头像 → 填身高/体重/体脂/目标 → 保存。面板应显示摄入、运动消耗、热量差、BMI。
2. **记饮食**：面板里选一个餐选项点「记下」；或在聊天说「我吃了一碗牛肉面」。
3. **记运动**：聊天说「今天跑了 5 公里，32 分钟」；面板「运动消耗」应更新。
4. **组间计时**：面板「组间休息」点 90 秒；卡片开始倒计时，结束后响铃/震动。
5. **周报**：面板「预览」看本周数字；点「推送到已绑定渠道」，没绑渠道时应提示只进应用内收件箱。
6. **拍照识餐**（配了视觉模型才有）：面板「拍照 / 选图」→ 选一张食物图 → 候选热量 → 确认后记账。
7. **导出**：面板「导出我的数据」→ 下载 JSON；确认里面没有密码、手机号等安全输入区的值。
8. **手机宽度**：浏览器开发者工具切 390px，或用手机访问；面板应变成底部抽屉。
